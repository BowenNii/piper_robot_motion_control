# PiPER 单位形静态正运动学一致性验证

## 1. 实验目的

- 验证 CAN 日志解码流程，并比较：
- 根据关节角和 URDF 推导的 POE 模型计算的末端位姿；
- CAN 报文反馈的末端位姿。

# 2. 实验条件

- 整理日期：2026-10-02
- 数据来源：piper_can.log
- 机械臂：PiPER 标准版
- 实验状态：静止位姿
- 夹爪及负载：无

## 3. 文件说明

- piper_can.log：原始 CAN 日志，仅复制、重命名，不修改内容。
- data.csv：C++ 解码及 POE 对比结果，单位为秒、弧度、米。
- matlab_plot.m：复制到matlab可以读取 CSV，绘制关节角、末端位置和误差曲线。
- report.md：本次实验记录。

## 4. 处理方法

1. 读取日志中的时间戳、报文 ID 和数据字节。
2. 将 0x2A2～0x2A7 六帧按不超过 2 ms 的时间窗口配对。
3. 解码六关节角度、末端 XYZ 和 RPY。
4. 利用关节角计算 POE 正运动学。
5. 比较 POE 位姿与反馈位姿，导出 CSV 并使用 MATLAB 绘图。

相对时间以第一组完整反馈为零点。
每组时间戳取最后一帧的接收时间，不保证硬件同步采样。

## 5. 实验结果

- 日志行数：4448
- 完整反馈组数：383
- 位置误差：约 0.0862005 mm
- 姿态误差：约 0.001213744°
- 六帧最大接收时间跨度：约 0.824 ms

当前数据为静态反馈，关节角和末端位置曲线基本保持不变。

## 6. 结论与局限

本次验证表明：当前位形下，POE 模型计算结果与厂家
CAN 反馈基本一致，日志解码和 CSV 导出流程能够正常运行。

383 组反馈属于同一静止位形，不能替代多位形验证。
厂家反馈不是独立外部测量，因此本结果不代表机械臂实际定位精度。
MATLAB 本次用于绘图分析，尚未进行独立算法交叉验证。
